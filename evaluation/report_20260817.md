# XBot HarnessBench 评估报告（2026-08-17）

## 摘要

本报告记录插件化重构后的第一个 minimax 全量运行：
`harnessbench-xbot-m3-0b806a7`（commit `0b806a7`，MiniMax-M3，
104 任务口径，`-j 4`，单次完整运行，wall time 1:18:42）。

被测代码即当前 HEAD（`0b806a7`），工作树带未提交改动，但未提交部分仅限
README/PROJECT_RESUME 与评估基建（`run_harnessbench.py`、评估 Dockerfile），
不影响被测 XBot 运行时；run-manifest 如实记录 `git_tracked_dirty: true`。

本报告做三件事：

1. **延续既有 104 任务口径**：与原始基线、XBot old、稳定点、OpenCode 对照、
   269aa3 双 Provider 同一表格横向比较。
2. **配对对比**：新 run 相对稳定点、269aa3 M3、269aa3 DeepSeek、OpenCode、
   Old、基线。
3. **照实记录运行异常**：本次运行出现 4 个 sample 重试（上游 Inspect/Anthropic
   桥接问题与一次 HarnessBench 超时），全部在自动重试后完成，未做任何现场修复。

结论要点：

- **插件化重构在 minimax 上不降反升**。104 任务口径 mean **0.8506**，是当前
  代码线（269aa3 之后）的最好 minimax 结果：相对稳定点配对 +0.0298（95% 区间
  `[+0.0042, +0.0554]`，不含零），相对 269aa3 M3 +0.0124（35 胜 / 19 负 /
  50 平，区间 `[-0.0097, +0.0345]`）。
- **效率同步改善**：总 token 21.36M（269aa3 M3 为 24.80M，-14%），每任务模型
  调用 14.53（-10%），sample 总耗时 17,009s（-5%）。
- **代价是工具失败率上升**：ACP 工具失败率 4.41%，高于 269aa3 M3（2.48%）与
  DeepSeek（2.37%）。结合 4 个重试样本判断，本次桥接层波动（reasoning 空块、
  流式索引错）是主要贡献者，语义失败与传输失败尚未逐条拆分。
- 历史 Old（0.8591）仍是全部记录中的最高分，但新 run 相对 Old 配对
  -0.0085，区间 `[-0.0316, +0.0146]`，单次观测下统计不可分。
- 主要修复集中在 `079`（+0.5422）、`052`（+0.3100）、`086`（+0.2850）、
  `072`（+0.2800）；主要回归集中在 `105`（-0.3225）、`077`（-0.3103）、
  `078`（-0.2963）、`057`（-0.2308）。
