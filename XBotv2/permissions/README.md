# Permissions

Tool authorization and live approval. Public models and service contracts live in
[`api/models.py`](api/models.py), events in [`api/events.py`](api/events.py), and
wire responses in [`api/protocol.py`](api/protocol.py). The implementation and
plugin entry point are in `impl/`; see [design](doc/design.md).
