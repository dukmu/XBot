# Thread task list

Owns persisted task snapshots and reminder counters. It depends on thread state, loop, tools and events; its HTTP route additionally depends on server and sessions. The registered task_create, task_get, task_update, task_delete and task_list tools use normal tool execution. Reminders and compaction may add runtime notices to prompts. Defaults: max_tasks 50, max_subject_chars 500, max_description_chars 2000, max_active_form_chars 200, reminder_after_turns 3, verification_nudge true; configuration is resolved on activation. Dispatch `GET_TODOS` with `EmptyRequest()` to read a `TaskList`; `TaskChanged` reports updates.
